# 🌸 Welcome

這個故事，

開始於一位哥哥。

哥哥很喜歡科學，

總想把自己的發現分享給妹妹。

可是妹妹說：

> **「哥哥，我看不懂。」**

於是，

哥哥沒有放棄。

他把真正的科學，

變成一個又一個童話故事。

因為他希望，

有一天，

妹妹會笑著說：

> **「哥哥，我也喜歡科學。」**
